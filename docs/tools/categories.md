# Categories

Four tools cover categories. Creating, updating, and deleting them requires a project manager (or an app admin). Listing is a read tool.

| Tool | Description | Example |
| --- | --- | --- |
| `get_categories` | List categories | "Show me all task categories" |
| `create_category` | Add a category | "Create a Bug Fixes category" |
| `update_category` | Rename or change a category | "Rename Bug Fixes to Critical Issues" |
| `delete_category` | Remove a category | "Delete the unused category" |
