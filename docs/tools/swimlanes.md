# Swimlanes

Four tools cover swimlanes. Creating, updating, and deleting them requires a project manager (or an app admin). Listing is a read tool.

| Tool | Description | Example |
| --- | --- | --- |
| `get_swimlanes` | List swimlanes | "Show me all team swimlanes" |
| `create_swimlane` | Add a swimlane | "Create a Frontend Team swimlane" |
| `update_swimlane` | Rename or change a swimlane | "Rename Mobile Team to Cross-Platform Team" |
| `delete_swimlane` | Remove a swimlane | "Delete the inactive team swimlane" |
