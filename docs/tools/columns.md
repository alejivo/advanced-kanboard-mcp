# Columns

Five tools cover columns. Creating, updating, deleting, and reordering them requires a project manager (or an app admin). Anyone who can see the project can list columns when that read tool is enabled.

| Tool | Description | Example |
| --- | --- | --- |
| `get_columns` | List columns | "Show me all columns in this project" |
| `create_column` | Add a column | "Create a Testing column with a limit of 5 tasks" |
| `update_column` | Change a column | "Change the Review column limit to 3 tasks" |
| `delete_column` | Remove a column | "Delete the unused Draft column" |
| `reorder_columns` | Change column order | "Move the Testing column before Done" |
